# TravStats v1.0.0

After six months of public beta and a full black-box pentest with all findings
mitigated, TravStats reaches its first stable release. **It's a self-hosted
flight tracker for small households and groups — 1–10 users — with
everything staying on your own machine.**

> **Upgrading from a 0.x beta?** Pull the new image from GHCR
> (`ghcr.io/abrechen2/travstats:1.0.0`), restart, and let the Prisma migration
> run. The default Ollama model is now `gemma3:12b` — pull it with
> `docker exec travstats-ollama ollama pull gemma3:12b` or override
> `OLLAMA_MODEL`. See breaking changes at the bottom.

## Highlights

### ✈️ Track however you like
- Manual entry · boarding-pass scanner (QR / PDF417 / OCR) · email import
  (text, HTML, `.msg`, `.eml`) with optional local LLM parsing
- Five flight states — flown, scheduled, cancelled, historical, duplicated
- Duplicate detection with a confirmed "save anyway" escape hatch

### 🗺️ Six map modes
Routes · Heatmap · Hexagon (3D) · 3D Columns · animated Trips · 3D Globe.
Built on deck.gl 9 + MapLibre 5.

### 📊 Statistics that actually tell a story
Year-over-year comparison, seat/class/zone distribution, top routes, cost
tracking, PDF year report, vintage-passport PNG certificate you can share.

### 🏆 58 achievements across 5 categories
Sammler, Distanz, Elite, Entdecker, Survivor — plus Planner and Special tiers.

### 🤖 Automation that stays local
- Auto-lookup via AirLabs / OpenSky / Aviationstack with a pending-update
  inbox so nothing changes without you approving it
- Historical enrichment scheduler backfills gate/terminal/aircraft for past
  flights
- 24 h / 2 h pre-departure SMTP reminders
- Automated database backups with retention + optional WebDAV off-site sync

### 🔐 Security you can actually audit
- JWT in HttpOnly cookies, 15 rate limiters, Zod validation on every
  endpoint, Prisma-parameterised queries, Helmet CSP, invite-only by default
- 22 pentest findings (2 CRITICAL, 5 HIGH, 8 MEDIUM, 7 LOW) surfaced and
  mitigated; reproducible verification commands in [SECURITY.md](../../SECURITY.md)

### 🐛 Friction-free bug reports
The **Bug** button in the top nav generates an anonymised diagnostic bundle
— log tails, per-user flight-state aggregates, settings (no credentials) —
and a single click both copies it to your clipboard and opens a pre-filled
GitHub Issue Form with the version field populated.

## Installation

```bash
curl -O https://raw.githubusercontent.com/Abrechen2/TravStats/main/docker-compose.prod.yml
curl -O https://raw.githubusercontent.com/Abrechen2/TravStats/main/.env.prod.example
mv .env.prod.example .env
nano .env                                              # set DB_PASSWORD
docker compose -f docker-compose.prod.yml up -d
open http://localhost:3000/setup
```

Unraid users: a
[Community Apps template](https://github.com/Abrechen2/TravStats/blob/main/docs/unraid/travstats.xml)
is available.

## Breaking changes from 0.x

- **Registry moved** to GHCR (`ghcr.io/abrechen2/travstats`). The old Docker Hub
  image is no longer updated.
- **Default LLM model** is now `gemma3:12b` (was `qwen2.5:7b`). Pull the new
  model or override `OLLAMA_MODEL`.
- **Parser-feedback collection removed.** The `/admin/parser-feedback/*`
  endpoints and the `FeedbackAnalytics` admin tab are gone. The separate
  `ParseTrainingLog`-backed hit-rate dashboard is unchanged.
