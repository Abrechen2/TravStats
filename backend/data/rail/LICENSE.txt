This file is a derivative database of that source, and is itself made available
under the ODbL v1.0. It was produced by backend/scripts/build-rail-stations.mjs:
the rows with coordinates and is_suggestable = t, plus the parent stations they
reference when those have coordinates, reduced to the columns id, name, uic,
db_id, lat, lon, country, time_zone and parent. Nothing else was changed. The
script is the complete description of the transformation; run it against the
source file to reproduce this one.
